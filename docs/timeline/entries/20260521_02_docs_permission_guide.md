# ⏳ 20260521_02_docs_permission_guide

## 1. 개요 (Overview)
- **일자**: 2026-05-21
- **유형**: `docs`
- **작업자**: Antigravity (박부장 에이전트)
- **요약**: IDE의 터미널 명령어 실행 권한 팝업창 원인 및 반복 질문 방지 설정(지속 허용 옵션) 가이드 작성.

## 2. 상세 내역 (Detailed Changes)
### 현상 및 원인 분석
- **현상**: `git log -n 20 --oneline` 실행을 위한 보안 승인 팝업창("Allow running this command?")이 활성화됨.
- **원인**: IDE의 샌드박스 보안 메커니즘으로 인해, 에이전트가 로컬 셸 명령어를 실행하려 할 때 오작동 방지 목적으로 사용자에게 최종 승인을 확인하는 절차임.

### 해결 방안 (반복 질문 방지 방법)
- **팝업창 내 2번 옵션 선택**:
  - `Yes, and always allow 'git log'` 옵션을 선택하고 `Submit` 버튼을 클릭.
  - 해당 옵션을 선택하면 해당 명령어 접두어(`git log`)에 대한 실행 권한이 IDE 보안 화이트리스트에 영구 등록되어, 이후 동일한 명령어 계열 실행 시 확인 창 없이 즉시 자동 실행됨.

## 3. 검증 결과 (Verification Results)
- 사용자 문의에 대한 IDE 보안 가이드 및 팝업창 인터페이스 매핑 완료.
