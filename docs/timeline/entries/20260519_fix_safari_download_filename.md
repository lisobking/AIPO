# 🛠️ Fix: 브라우저 Blob 다운로드 파일명 누락 및 UUID 파일 다운로드 버그 해결

- **일시:** 2026-05-19
- **담당 에이전트:** 개발자 1 (클코), PM (박부장)
- **작업 유형:** `fix`
- **Git Commit:** `N/A`

## 🎯 버그 현상 (Issue Description)
- 사용자가 공수산정서를 업로드하여 견적서 생성을 시도했을 때, 서버 측에서는 정상적으로 Excel 생성이 완료(HTTP 200, 5.7KB)되었으나, 크롬/사파리 다운로드 창에는 지정된 파일명(`견적초안_[파일명].xlsx`)이 아닌, Blob 객체의 내부 UUID(예: `9a5496b3-a99c-4d60-9e73-781a2c0928c7`) 형태로 확장자 없이 파일이 다운로드되는 현상 발생.

## 🔍 원인 분석 (Root Cause)
- 프론트엔드(`web/index.html`)의 드롭존 스크립트에서 다운로드를 트리거하기 위해 `a.click()`을 호출한 직후, 단 **200ms**만에 `window.URL.revokeObjectURL(url)`을 실행하여 리소스를 회수함.
- 브라우저의 다운로드 엔진이 실제 스트림과 메타데이터(파일명 및 타입 등)를 완전히 해석하여 디스크 파일 생성 협상을 끝내기 전에 원본 Blob URL이 파괴되면서, 브라우저는 임시 해석 캐시에 남아있던 고유 UUID 문자열을 파일명으로 사용해 무명 파일로 내려받게 됨.

## 🛠️ 조치 사항 (Actions Taken)
1. **`web/index.html` 내 URL 해제 지연 시간 연장**:
   - `revokeObjectURL`을 호출하는 `setTimeout` 딜레이 값을 200ms에서 **15,000ms(15초)**로 대폭 연장.
   - 브라우저가 파일 쓰기 및 명명 규칙 처리를 끝마칠 수 있는 충분한 시간을 보장.
2. **서버 재기동**:
   - 백그라운드에서 동작 중이던 Flask 서버 포트(5001) 프로세스를 정상 종료(kill) 후 리로드하여 변경 사양이 즉각 배포되도록 조치.

## ✅ 결과 검증 (Verification)
- 브라우저의 리소스 유지 시간 증가로 인해 정상적인 파일 포맷과 의도했던 파일 명칭(`견적초안_[업로드파일명].xlsx`)으로 다운로드가 안정적으로 완료됨을 확인.

## ⏭️ 다음 작업자를 위한 인수인계 (Handover)
- 향후 대용량 파일 다운로드 흐름이 필요한 경우에도 Blob URL 해제 시 충분한 지연 시간을 확보하거나, 세션 이탈 시점에 일괄 정리하는 패턴을 권장함.
