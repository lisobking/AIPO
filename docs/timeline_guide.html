듀얼 타임라인 시스템 활용 가이드

AutoPO Project: 거시적 문맥(Macro)과 미시적 코드(Micro)의 완벽한 동기화

🌍 두 가지 타임라인의 이해

이 프로젝트는 AI 에이전트의 환각을 방지하고 컨텍스트를 최적화하기 위해 두 가지 타임라인을 연동하여 사용합니다.

  • 프로젝트 타임라인 (Macro): docs/timeline/ 디렉토리에 마크다운으로 기록되는 기능 단위의 기획 및 인수인계 문서입니다.
  • VS Code 타임라인 (Micro): 에디터 좌측 하단에 위치하며, 파일 저장 내역(Local History)과 Git 커밋(Commit) 내역을 코드 라인 단위로 추적합니다.

🚀 실전 활용 워크플로우

1

작업 완료 및 자율 기록

개발자 에이전트(박부장)가 코드를 수정 완료하면, PM 에이전트가 이를 감지하여 자율적으로 docs/timeline/entries/에 상세 마크다운 문서를 생성합니다.

2

Git 커밋 동기화

개발자는 코드를 Git에 커밋할 때, 타임라인 문서의 접두어를 커밋 메시지에 포함시킵니다.
예: git commit -m "[20260519_feat] 엑셀 파싱 엔진 수정"

3

마스터 인덱스 갱신

PM 에이전트는 해당 Git Commit Hash 값을 docs/timeline/index.md 표에 기록하여 문서와 실제 코드를 강력하게 연결합니다.

🔍 문제 해결 (디버깅) 방법론

🔽 Top-Down 추적 (기획 의도에서 코드 찾기)
1. index.md에서 작업 내역과 Git Commit Hash 확인
2. VS Code 하단 타임라인에 Hash 검색
3. 해당 기능 개발 시 정확히 변경된 코드 라인만 확인 및 수정
🔼 Bottom-Up 추적 (코드에서 기획 의도 찾기)
1. 이해가 안 가는 코드를 VS Code 타임라인에서 클릭하여 커밋 메시지 확인
2. 메시지 앞의 태그 (예: [20260519_feat]) 확인
3. docs/timeline/entries/ 폴더에서 해당 태그의 파일 열람하여 기획 의도와 검증 내용 파악
